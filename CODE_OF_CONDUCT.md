# Code of Conduct

Be respectful, be constructive, assume good faith. Disagree about code and
decisions freely; don't make it personal.

Harassment, discriminatory language or jokes, and personal attacks aren't
welcome here. Maintainers may edit, close, or remove issues, PRs, comments,
or contributors that don't meet this bar, at their discretion.

If something happens that you'd rather not raise in public, open a private
GitHub security advisory on this repo, or contact the maintainer directly
via their GitHub profile.

This is intentionally short. Read the spirit of it, not the letter.
